# YeetnGreet docs

YeetnGreet helps **internal IT teams** onboard and offboard Microsoft 365 users from a Windows PC, without putting your tenant data in our cloud. It works for a single tenant or for teams that manage several, such as a parent company with subsidiaries.

Microsoft Graph runs on your IT team’s machines. We only use the cloud for your YeetnGreet **license and billing**.

!!! note "Cloud-only Microsoft 365"
    YeetnGreet works with cloud-only Microsoft 365 (Entra ID). Hybrid and on-premises Active Directory are not supported yet.
