# What-if

Model license changes before you buy or cut — useful for budgeting and renewal planning.

## When to use it

- “What if we move these users to SKU B?”
- Comparing seat counts after a department change
- Pairing with [unused seats](unused-seats.md) for a reclaim + right-size plan

## Steps

1. Select the tenant
2. Open **Reports → What-if**
3. Set the scenario you want to compare
4. Review the projected outcome; export or [deliver](delivery.md) if needed

!!! tip "Keep scenarios named"
    Save clear names (“Q4 reclaim + E3→E1 wave”) so the next person on your team can reuse them.
