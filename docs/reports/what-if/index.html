What-if¶

Model license changes before you buy or cut — useful for quoting and renewal planning.

When to use it¶

  • “What if we move these users to SKU B?”
  • Comparing licensed-user counts after a department change
  • Pairing with unused licenses for a reclaim + right-size story

Steps¶

  1. Select the tenant
  2. Open Reports → What-if
  3. Set the scenario you want to compare
  4. Review the projected outcome; export or deliver if needed

Keep scenarios named

Save clear names (“Q4 reclaim + E3→E1 wave”) so the next tech on the account can reuse them.
